۳. Cloudflare Pages پر لائیو کرنا

  1. Cloudflare میں لاگ اِن کریں ← Workers & Pages ← Create ← Pages ← Upload assets (Direct Upload)۔
  2. پراجیکٹ کا نام لکھیں، پھر prayertim-site فولڈر (یا اس کی ZIP) ڈال دیں اور Deploy دبائیں۔
  3. پراجیکٹ کے Custom domains میں prayertim.com شامل کریں اور Cloudflare کی ہدایات کے مطابق DNS درست کریں۔
  4. لائیو ہونے کے بعد دیکھ لیں: https://prayertim.com/sitemap.xml اور https://prayertim.com/ads.txt کھلتے ہیں۔

۴. Google Search Console (پہلے یہ کریں)

  1. search.google.com/search-console میں prayertim.com شامل کریں اور ملکیت ثابت کریں (DNS طریقہ آسان ہے)۔
  2. Sitemaps میں sitemap.xml جمع کروائیں۔
  3. چند ہفتے رکیں تاکہ Google صفحات انڈیکس کر لے۔

۵. AdSense کے لیے اپلائی

  1. AdSense میں سائٹ prayertim.com شامل کریں۔ Google آپ کو ایک کوڈ اور Publisher ID (جیسے ca-pub-1234567890123456) دے گا۔
  2. کمپیوٹر پر Python چلا کر یہ ایک لائن چلائیں (فولڈر کے برابر میں):
    python3 tools/add-adsense.py ca-pub-آپکی-اصل-ID prayertim-site
    یہ تمام صفحات میں کوڈ ڈال دے گا اور ads.txt بھی بھر دے گا۔ اس کے بعد prayertim-site دوبارہ اپلوڈ کریں۔ (یا مجھے اپنی ID بھیج دیں، میں سائٹ دوبارہ بنا دوں گا۔)
  3. AdSense میں Privacy & messaging کے اندر یورپ/برطانیہ کے لیے Google کا مفت consent پیغام آن کریں۔ یہ ان ممالک کے وزیٹرز کے لیے ضروری ہے۔
  4. جب AdSense "تیار" کہے تو جائزے کے لیے بھیجیں۔ منظوری کے بعد Auto ads آن کر لیں۔ ابھی صفحات میں خود اشتہاری ڈبے رکھنے کی ضرورت نہیں۔
اہم: منظوری کی ضمانت کوئی نہیں دے سکتا۔ Google ہر سائٹ کو خود دیکھتا ہے۔ اپنی ہی سائٹ کے اشتہار پر کلک نہ کریں، اور نیچے والی باتوں کا خیال رکھیں۔
